# Games Shop

Site institucional de uma loja de games, com seção "Sobre a loja", formulário de contato, redes sociais e endereço.

**Demonstração:** https://site-gamesshop-smoky-theta.vercel.app

## Como executar

Abra o arquivo `index.html` no navegador.

## Tecnologias

- HTML5
- CSS3 (Flexbox e variáveis CSS)
- Google Fonts (Bungee e Roboto Flex)
